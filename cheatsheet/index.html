Dotfiles Cheat Sheet

Keybindings & behavior for the current setup. Modifier alt = ⌥ Option.

AeroSpace — Window Manager

Config: aerospace/aerospace.toml · prefix modifier is alt. Enter service mode with alt+shift+;, then press one key (esc reloads config & exits).

Focus window

alt+h / ←Focus left
alt+j / ↓Focus down
alt+k / ↑Focus up
alt+l / →Focus right

Move window

alt+shift+h / ←Move left
alt+shift+j / ↓Move down
alt+shift+k / ↑Move up
alt+shift+l / →Move right

Layout

alt+/Tiles layout (horiz/vert)
alt+,Accordion layout (horiz/vert)
alt+`Toggle floating / tiling

Resize

alt+-Shrink −50 (smart)
alt+=Grow +50 (smart)

Workspaces

alt+1…9Switch to workspace 1–9
alt+a…zSwitch to lettered workspace (A, B, … Z)
alt+tabBack-and-forth (last workspace)

Send window to workspace

alt+shift+1…9Move window to workspace 1–9
alt+shift+a…zMove window to lettered workspace

Monitors & reassign

alt+shift+tabMove workspace to next monitor
alt+shift+=Reassign all windows to pinned workspaces, then follow the focused one

Service mode — alt+shift+;

escReload config & exit
rReset layout (flatten tree)
fToggle floating / tiling
backspaceClose all windows but current
alt+shift+h/j/k/lJoin with left/down/up/right
↓ / ↑Volume down / up
shift+↓Mute (volume 0) & exit
